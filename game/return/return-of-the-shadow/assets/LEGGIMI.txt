CARTELLA ASSETS
===============

Questa cartella è opzionale: il gioco non ha bisogno di alcun asset esterno
(tutta la grafica e l'audio sono generati dal codice).

Se vuoi un carattere serif/runico personalizzato per la title screen
"THE RETURN OF THE SHADOW", copia qui un font TrueType con il nome:

    assets/title.ttf

Verrà caricato automaticamente all'avvio (vedi la sezione "Font" in main.lua).
Se il file non esiste, il gioco usa il font di sistema di LÖVE con spaziatura
allargata tra le lettere — perfettamente funzionante comunque.

Suggerimento: scegli un font con licenza libera (ad es. SIL Open Font License).
